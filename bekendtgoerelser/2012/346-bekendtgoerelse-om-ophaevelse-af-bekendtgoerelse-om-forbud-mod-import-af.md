# Bekendtgørelse om ophævelse af bekendtgørelse om forbud mod import af foderprodukter med indhold af visse frø og bønner fra Egypten

*BEK nr 346 af 18/04/2012*

Bekendtgørelse nr. 3 af 4. januar 2012 om forbud mod import af foderprodukter med indhold af visse frø og bønner fra Egypten ophæves fra og med den 20. april 2012.

Fødevarestyrelsen, den 18. april 2012

Esben Egede Rasmussen

/ Jan Thiele
