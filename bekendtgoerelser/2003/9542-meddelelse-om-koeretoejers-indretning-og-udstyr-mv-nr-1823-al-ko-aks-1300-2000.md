# Meddelelse om køretøjers indretning og udstyr mv. nr. 1823 AL-KO AKS 1300 / 2000 / 2002 / 2004 / 3004 kuglekobling med stabiliseringsanordning.

*BEK nr 9542 af 22/09/2003*

AL-KO kuglekobling, type AKS, er en 50 mm kuglekobling, der er indrettet således, at den efter tilkobling til det trækkende køretøj kan spænde om koblingskuglen i to punkter i horisontalt plan ved hjælp af en fjeder og et udvekslingssystem. Herved opnås en stor friktionskraft mellem kuglen og koblingens to tryksko, hvorved påhængskøretøjets sideværts bevægelser dæmpes under kørsel.

VEJLEDNING

Påhængskøretøjet er forsynet med AL-KO AKS1300/2000/2002/2004/3004 kuglekobling med stabilisator og må derfor kun sammenkobles med biler, der er forsynet med følgende tilkoblingsanordninger (træktøjstyper).

| 1. Bosal | - alle typer |
|---|---|
| 2. Brenderup | - hvor kuglen er mærket: ISO 50.<br>Aftageligt system 61 eller 65 Automatic |
| 3. Brink | - alle typer |
| 4. Dansk Anhængertræk | - hvor kuglen er mærket: ISO 50 |
| 5. Kovil OY | - hvor kuglen er mærket: ISO 50 |
| 6. NK Nordisk Komponent | - hvor kuglen er mærket: ISO 50 |
| 7. VBG | - alle typer |
| 8. Søborg Vognfjeder Fabrik | - hvor kuglen er mærket: ISO 50. |
| Uanset ovenstående må AKS1300/2000/2002/2004/3004 kuglekobling dog ikke anvendes på koblingskugler, hvor kuglehalsen er fastgjort med møtrik som vist på tegning, eller hvor målet “X” er mindre end 60 mm. | ![AR726\_2.JPG Size: (94 X 95)](https://www.retsinformation.dk/image.aspx?id=22243&img=AR726_2.JPG) |

Påhængskøretøjet skal ikke til syn ved udskiftning af kuglekoblingen.

Anvendelse af påhængskøretøj monteret med AL-KO AKS1300/2000 /2002/2004/3004 kuglekobling :

Anvendelse må kun ske i henhold til ovenstående vejledning.

Optagelse på vejledningen :

Øvrige fabrikater/typer af tilkoblingsanordninger vil efter ansøgning kunne optages på vejledningen. Ansøgninger skal være bilagt en erklæring fra fabrikanten af tilkoblingsanordningen, om at der må anvendes AL-KO AKS1300/2000 stabilisator på denne.
