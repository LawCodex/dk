# Bekendtgørelse om ophævelse af bekendtgørelse om registrering af og tilsyn med visse private sygehuse, klinikker og praksis

Bekendtgørelse nr. 835 af 27. juni 2014 om registrering af og tilsyn med visse private sygehuse, klinikker og praksis ophæves.
