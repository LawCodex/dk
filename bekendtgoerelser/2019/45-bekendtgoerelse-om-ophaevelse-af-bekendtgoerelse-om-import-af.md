# Bekendtgørelse om ophævelse af bekendtgørelse om import af cannabisudgangsprodukter og fremstilling af cannabismellemprodukter og bekendtgørelse om dyrkning, fremstilling og distribution af cannabisbulk og fremstilling af cannabisudgangsprodukter

*BEK nr 45 af 11/01/2019*

## § 1.

Følgende bekendtgørelser ophæves:

- 1\) Bekendtgørelse nr. 1720 af 26. december 2017 om import af cannabisudgangsprodukter og fremstilling af cannabismellemprodukter.
- 2\) Bekendtgørelse nr. 943 af 28. juni 2018 om dyrkning, fremstilling og distribution af cannabisbulk og fremstilling af cannabisudgangsprodukter.

## § 2.

Bekendtgørelsen træder i kraft den 17. januar 2019.

Sundheds- og Ældreministeriet, den 11. januar 2019

Ellen Trane Nørby

/ Mie Saabye
